# LingWay

Сайт для подготовки к поездкам за границу: слова и фразы по ситуациям (аэропорт, отель, кафе и другие), диалоги и тренировка речи на английском. Интерфейс на русском.

Сайт: https://f5049f63.github.io/LingWay/

## Технологии

- Клиент: React, TypeScript, Vite, Tailwind CSS, React Router
- Сервер: Node.js, Express, TypeScript, Zod
- База данных: PostgreSQL (Neon), Prisma
- Публикация: GitHub Pages (клиент), Render (сервер)

## Структура

```
client/    сайт (React)
server/    серверная часть (Express) и база данных (server/prisma)
docs/      документация (API и другое)
```

## Быстрый старт

Нужен Node.js 20.19 или новее.

```bash
git clone https://github.com/f5049f63/LingWay.git
cd LingWay
git checkout dev

npm install
cp server/.env.example server/.env      # заполнить значения
cp client/.env.example client/.env
npm run dev
```

Сайт откроется на http://localhost:5173/LingWay/, сервер на http://localhost:3000.
Проверка сервера: http://localhost:3000/api/health

Строки подключения к базе (`DATABASE_URL`, `DIRECT_URL`) выдаёт владелец проекта лично. В репозиторий они не попадают.

## База данных

Схема лежит в `server/prisma/schema.prisma`. Изменения схемы делаются через миграции:

```bash
cd server
npx prisma migrate dev --name что_изменилось
```

Файл миграции нужно закоммитить. Не применяй новые миграции к общей базе Neon сам: у роли `team` из `server/.env` нет прав менять схему (будет `permission denied`). Их применяет владелец проекта под ролью владельца. Остальным участникам после `git pull` достаточно выполнить `npm run db:generate`, чтобы обновить Prisma-клиент. Проверять свою миграцию лучше на локальном PostgreSQL.
База общая для ветки `dev`, поэтому тестовые записи других участников не удаляй.

## Ветки и коммиты

- `main`: опубликованная версия сайта, напрямую в неё не коммитим
- `dev`: общая рабочая ветка
- Работа в личных ветках `имя/задача` от `dev`, слияние через pull request
- Перед началом работы `git pull`, после задачи `git push`
- Сообщения коммитов: `feat: ...`, `fix: ...`, `style: ...`, `docs: ...`, `chore: ...`
- Один коммит содержит одно логическое изменение

## Восстановление пароля локально

Почта на локальном сервере не настроена: письмо со ссылкой для сброса пароля печатается в консоль сервера (окно, где запущен `npm run dev`). Скопируйте ссылку оттуда. Чтобы письма уходили по-настоящему, заполните `SMTP_*` в `server/.env`.
