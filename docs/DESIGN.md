# Дизайн LingWay

Правила в коде. Проверка: `npm run check:design` (запускать перед коммитом).

## Основа

- Шрифт один: Manrope (поддерживает кириллицу). Без курсива, максимум semibold/bold.
- Цвета в два слоя, всё в `client/src/index.css`:
  1. `--core-*`: сырые палитры (Primary, Grayscale, Red, Green, Yellow). Hex только здесь.
  2. Семантические токены с режимами Light и Dark: `bg-surface`, `bg-surface-subtle`, `border-border`, `text-ink`, `text-muted`, `text-subtle`, `bg-action`, `text-info` и т.д. В компонентах использовать только их.
- Тёмная тема: класс `dark` на `<html>`, переключатель в шапке. Фоны только из набора #000000, #181818, #1F1F1F, #272727, #313131, #131209.
- Тени, выпуклости, глянец, размытые пятна и градиенты не используем: кнопки, карточки и фон плоские, с рамкой. Единственное исключение: текст заголовка hero (`hero-text`).
- Объём делаем композицией, а не тенями: наклон в 3D (`Tilt`), перекрывающиеся слои на разной глубине, стопка карточек со sticky, штампы (`Stamp`). Поверхности: `mat-raised`, `mat-lifted`, `mat-sunken`, `mat-glass`, `mat-action`, `mat-ink` (плоская заливка и рамка).
- Акцент один: терракота (Primary 500, `#C73E1D`). Светлая тема на тёплой «бумаге» (`#F8F5EE`), тёмная на `#131209`.
- Визуальная тема: посадочный талон и маршрут. Цветные плитки бенто: акцент, тёмная, светлая, белая.

## Текстовые стили

Классы: `heading-1…6`, `title-1…5`, `body-1…6`, `button-lg/md/sm/xsm`, `caption-1…5`. Размер и жирность вручную не задавать. На мобильном крупные заголовки спускаются на ступень шкалы Tailwind ниже.

## Отступы и радиусы

- Отступы только: 0, 0.5, 1, 2, 3, 4, 6, 8, 10, 12, 16, 20, 24 (в Tailwind-единицах; это 0, 2, 4, 8, 12, 16, 24, 32, 40, 48, 64, 80, 96 px).
- Радиусы только из Tailwind. Вложенная форма в зазоре меньше 32px: радиус вложенной = внешний − зазор (если больше 2).
- Основные кнопки: padding 8 и 12 px; крупная кнопка CTA: 12 и 16 px.

## Движение

- Кривая `ease-brand` = cubic-bezier(0.22, 1, 0.36, 1). 500ms для положения, 300ms для цвета и прозрачности. Анимируем только transform и opacity.
- Появление блоков: `<Reveal>` (IntersectionObserver, один раз). Раскрытие слов: `<TaglineReveal>`.
- `prefers-reduced-motion` отключает движение.

## Иконки

Phosphor, один вес (regular): `import { XIcon } from "@phosphor-icons/react"`. Material Icons не используем.

## Тексты

Без дефисов и тире внутри слов и фраз, без восклицательных знаков, предложения в sentence case, без слов «революционный», «мирового класса» и подобных. Не выдумываем цифры, отзывы и цены: нет данных, пишем `{{заглушка}}`.

## Состояния

У каждого интерактивного элемента: hover, active (`scale-[0.98]`), focus (кольцо), disabled. Для данных: загрузка (скелетон, не спиннер), пусто, ошибка.

## Что уже сделано

Лендинг (`client/src/pages/Landing.tsx`), шапка, подвал, 404, страницы входа, регистрации, восстановления пароля, настроек и онбординга (`Welcome`), общие компоненты форм (`Field`, `PasswordField`, `Alert`, `ChoiceCard`). Остальные страницы пока заглушки. Новые страницы делаем по этим же правилам и тем же токенам, формы по образцу `Register.tsx`, а выбор из вариантов через `ChoiceCard`.
