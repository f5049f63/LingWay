# API

Базовый адрес: `http://localhost:3000` (локально). Все ответы в формате JSON. Ошибки: `{ "error": "текст" }`; при ошибках проверки полей добавляется `fields`: `{ "error": "...", "fields": { "email": "..." } }`.
При изменении или добавлении запросов обновляй этот файл.

## Сейчас есть

| Метод | Адрес             | Описание                                                               |
| ----- | ----------------- | ---------------------------------------------------------------------- |
| GET   | `/api/health`     | Сервер запущен: `{ "status": "ok", "time": "..." }`                    |
| GET   | `/api/health/db`  | Есть подключение к базе: `{ "status": "ok", "database": "connected" }` |
| GET   | `/api/situations` | Список ситуаций, отсортированный по `order`                            |

## Аккаунт

Вход держится на JWT в httpOnly cookie `token` на 7 дней. Клиент шлёт запросы с `credentials: "include"`.
Пароль: от 8 до 72 символов, хранится как хеш bcrypt. Объект пользователя: `{ id, email, name, role, onboarded, trip }`, где `onboarded`: прошёл или пропустил онбординг, а `trip`: `{ purpose, destination, level }` (все `null`, пока не отвечал или пропустил).
Смена и сброс пароля завершают все остальные сессии (старые токены перестают работать).

### Вход и регистрация

| Метод | Адрес                | Тело                        | Ответ                                                                                  |
| ----- | -------------------- | --------------------------- | -------------------------------------------------------------------------------------- |
| POST  | `/api/auth/register` | `{ name, email, password }` | 201 `{ user }` и cookie. 400 ошибки полей, 409 email занят, 429 слишком много запросов |
| POST  | `/api/auth/login`    | `{ email, password }`       | 200 `{ user }` и cookie. 400 ошибки полей, 401 неверные данные, 429 лимит попыток      |
| POST  | `/api/auth/logout`   |                             | 200 `{ ok: true }`, cookie удаляется                                                   |
| GET   | `/api/auth/me`       |                             | 200 `{ user }`. 401, если не вошли                                                     |

### Восстановление пароля

| Метод | Адрес              | Тело                  | Ответ                                                                                       |
| ----- | ------------------ | --------------------- | ------------------------------------------------------------------------------------------- |
| POST  | `/api/auth/forgot` | `{ email }`           | Всегда 200 `{ ok: true }` (не выдаём, есть ли такой email). На почту уходит ссылка на 1 час |
| POST  | `/api/auth/reset`  | `{ token, password }` | 200 `{ ok: true }`. 400 ссылка недействительна или устарела, либо пароль не подошёл         |

Ссылка в письме: `APP_URL/#/reset/<токен>`. Без настроенной почты (`SMTP_HOST` пуст) письмо не отправляется, а текст со ссылкой печатается в консоль сервера: так можно проверить сброс локально.

### Онбординг (нужен вход)

Короткий опрос после регистрации: цель поездки, страна и уровень английского. По ним клиент выстраивает маршрут ситуаций.

| Метод | Адрес                          | Тело                              | Ответ                                                                                            |
| ----- | ------------------------------ | --------------------------------- | ------------------------------------------------------------------------------------------------ |
| PUT   | `/api/account/onboarding`      | `{ purpose, destination, level }` | 200 `{ user }`, `onboarded: true`. 400 ошибки полей. Можно слать повторно, чтобы изменить ответы |
| POST  | `/api/account/onboarding/skip` |                                   | 200 `{ user }`, `onboarded: true`, уже сохранённые ответы не стираются                           |

Допустимые значения:

- `purpose`: `tourism`, `business`, `study`, `relocation`
- `destination`: `usa`, `uk`, `canada`, `australia`, `ireland`, `other`, `undecided`
- `level`: `A1`, `A2`, `B1`, `B2`

Список лежит в `server/src/lib/onboarding.ts`, такой же в `client/src/data/onboarding.ts`. Меняешь в одном месте, меняй в другом.

Лимиты на одного пользователя или адрес: вход 10 неудачных попыток за 15 минут, регистрация 20 в час, восстановление 5 в час, действия с паролем в настройках 10 неудачных попыток за 15 минут. При превышении 429.

## Планируется

- Аккаунт: перенос прогресса гостя после регистрации
- Контент: ситуация со списком уроков, урок с упражнениями
- Прохождение: ответ на упражнение, завершение урока
- Прогресс, словарь, повторение, настройки
